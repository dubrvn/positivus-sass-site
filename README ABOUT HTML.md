# html

## header
dialog — это тег, в котором будет всплывающие меню под бургер кнопкой. Модальные окна нужно всегда размещать в конце body. Это нужно, чтобы всплывающий элемент наверняка перекрыл весь остальной контент. 
По умолчанию, этот элемент не виден. Если задать атрибут open, тогда он отобразиться.
Этому тегу присваиваем id="mobileOverlay" в camel нотации для джаваскрипта.
А для бургер-кнопки, которая его будет открывать, пропишем onclick="mobileOverlay.showModal()". Мы ссылаемся на этот id и добавляем метод showModal() который есть только у dialog.

Чтобы закрыть модальное окно внутри ставим тег form c атрибутом method="dialog", а внутри кнопка для закрытия type="submit"


## section hero
Размечаем Section hero. тег параграфа оборачиваем в div с нужным классом, а сам тег параграфа без класса. Это нужно для комфортная заполнения контента через CMS, откуда прилетают данные без классов.

Гирлянда из логотипов партнёров получит унифицированные размеры. А дизайнер положить каждый логотип в унифицированный контейнер в макете, чтобы при разработке не пришлось додумывать самому.

## section process
Добавили в нумерованный список новый элемент details.

Тег <details> в HTML — это нативный способ сделать раскрывающийся блок: пользователь может кликнуть, чтобы увидеть скрытый контент, и свернуть его обратно. Всё работает без JavaScript — браузер сам управляет состоянием.

<details>
  <summary>Что такое details?</summary>
  <p>Это нативный раскрывающийся блок в HTML5. Он доступен по умолчанию и не требует JS.</p>
</details>
