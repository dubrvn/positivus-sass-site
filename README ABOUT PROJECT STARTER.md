# Sass файлы
Файлы стилей (кроме основного styles.scss) называем, начиная с нижнего подчеркивания.
Чтобы при компиляции в css, он их не использовал (иначе буду здавоения)

Подключение стилей в основной файл styles.scss
@use 'указываем имя без _ в начале файла и без указания расширения scss' as *.
Последовательность подключения файлов важна, чтобы они не конфликтовали дальше. Уточнение со звездочкой означает, что мне надо помечать имена названием файла родителя. Это может создавать конфликты, если имена задвоятся, но так писать короче. Надо быть аккуратным с именами.

Важно: Если я использую миксин из файла _mixins.scss в каком-либо другом файле sass через @include, мне нужно в начале файла указать @use 'mixins'.

@forward директива нужна, когда я хочу пачками разделить подключаемые файлы, а не писать @use по 10 раз.
Например в index.scss я ПЕРЕДАМ файлы
@forward '_functions.scss'
@forward '_helpers.scss'
Когда я захочу где-то включить содержания этих файлов, я подключу только
@use 'index.scss'

### Компиляция scss файлов в css
Стави node js
Инициализируем в папке проекта npm init
Ставим сасс npm install sass --save-dev
Или короче npm i sass -D
В package.json появится sass в dev dependencies

Пропишем команду в scripts (package.json)
"sass-watch": "sass --watch ."

Запускаем в терминале один раз, дальше он будет работать в автоматическом режиме.
Вводим в терминал npm run sass-watch
Далее, чтобы файлы однобновлялись, нужно сохраниться ctrl s каждый раз.
Выключить в терминале ctrl C

Подключаем styles.css (После title, но лучше перед script для js)
<link rel="stylesheet" href="./styles/styles.css" />

### _variables.scss
глобальные переменные: 
цвета, 
толщина и радиус скруглений у обводок, 
семейство шрифта,
параметры сетки,
высота кнопок и полей ввода,
длительность transition-duration.


### Подключаем шрифты
Качаем с гугл фонтс Space Grotesk все вариации шрифты
Выбираем 400 регуляр и 500 медиум. 
Преобразуем ttf в woff2 в сервисе https://transfonter.org/
Закидываем woff2 файлы в /fonts

В файле _fonts.scss прописываем шрифты через @font-face
свойство font-display: swap; сразу подключит подменный шрифт, пока оригинальный будет загружаться.


### _mixins.scss
@fluid-text отвечает за максимальный и минимальный размер шрифта, со значениями по умолчанию 48 и 16.
Внутри работает функция clamp (min px, среднее значение = (max / ширину десктопа * 100)vw, max px)

@mixin reset-link сбрасывает дефолтные оформление ссылок
@mixin reset-button сбрасывает дефолтное оформление кнопок
@mixin flex-center принимает булвое значение isInline в значении false по умолчанию. Центрирование уже зашито, можно переключаться между flex и строчным inline-flex
@mixin abs-center абсолютно центрирует элемент. Сдвигает верхний левый угол в центр родителя, смещает сам элемент на половину его ширины и высоты.
@mixin square квадратирует


### _media.scss
Записали переменные для контрольных точек, для мобайл и десктоп ферст.
А также миксины медиа-запросов.
Добавили миксин hover, который убирает залипание кнопки при нажатии на мобиле.


### _utils.scss
Утилитарные классы:
container ограничит контентную область.
visually-hidden прячет с экрана элементы.
hidden-mobile прячет элементы с мобилы
visible-mobile прячет элементы с десктопа


### _globals.scss
Глобальные переменные для всего сайта: семейство, цвет и размеры шрифта и пр.
