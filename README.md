# Верстка лендоса с использованием sass

Проект без сборщика. Для компиляции файлов в css:
```npm i sass -D```

Чтобы отслеживать изменения в scss файлах:
```npm run sass-watch```

## Особенности

### html
Мобильное меню в шапке размечено тегом dialog.
Внутри section и article используется тег header, объединяющий заголовок и описание.
В секции «Working process» список размечен тегом <ol>, а элементы списка размечены <details>, это нативный аккордеон без JS.

### media.scss
Содержит миксины медиазапросов для обоих подходов: desktop first и mobile first. В основном адаптив идет от сужения большого экрана к мабиле, но иногда поведением выгодно управлять от обратного.
Миксин hover убирает залипание кнопки при нажатии на мобиле.

### mixins.scss
–  fluid-text использует функцию clamp() для диапозона размера шрифта. Минимальный и максимальный в пикселях, значение между — во вьюпорт-единицах.
–  flex-center делает объект флексом или инлайн-флексом, с рядом свойств для центрирования.
–  abs-center центрирует объект при абсолютном позиционировании.
